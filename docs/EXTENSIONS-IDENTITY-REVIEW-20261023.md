The identity defaults protect fresh deployments from unrequested IAM changes. **Existing Terraform-managed groups, policies, or domains require their previous enable flags and domain map to be set explicitly before an upgrade plan.** Otherwise, Terraform may propose deletion. Review a saved plan and resolve that migration before applying. `home_region` must match the tenancy's actual IAM home region; it is not inferred from the Sao Paulo test region.
